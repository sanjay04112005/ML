# Student Exam Score Prediction

## Objective
Predict a student's exam score based on the number of hours studied.

## Dataset
The dataset contains:
- Hours – number of hours studied
- Scores – exam score

## Model Used
Simple Linear Regression

## Preprocessing
- Checked dataset information
- Checked missing values
- Checked duplicate rows
- No missing values or duplicates were found

## Train-Test Split
- Training data: 20 records
- Testing data: 5 records

## Results
- Mean Absolute Error (MAE): 3.92
- R² Score: 0.968

## Conclusion
The model was successfully trained to predict exam scores from study hours.
